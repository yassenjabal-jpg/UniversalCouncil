# Workforce Scorecard

Each active role is periodically scored on:
- Unique Contribution
- Decision Impact
- Evidence Quality
- Conviction
- Error Detection
- Execution Value
- Speed
- Duplication
- Tool / Skill Utilization
- Cost in time, context and complexity

Recommended outcomes:
- KEEP
- IMPROVEMENT_TRIAL
- MERGE
- REMOVE_WITHOUT_REPLACEMENT
- REPLACE
- FIRE_RECOMMENDATION

Scores never override material evidence. A high score cannot protect a role whose function is no longer needed, and a dissenting member is not penalized for disagreement itself.

When a role is proposed for REPLACE, HR must specify the expected added capability and a measurable review trigger for the replacement.
