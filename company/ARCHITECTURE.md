# Architecture

Owner → episodic Universal Council Board → Venture Operator → bounded workflows, with separate Finance and Assurance.

The durable Company Kernel remains the source of truth for state, grants, capabilities, actions, budgets, events, money, obligations, and evidence. ApprovedGateway is the only sanctioned execution boundary. LLM output can propose typed actions but cannot authorize itself.

No permanent agent per title. A function may split only when a measured bottleneck and target metric justify added complexity.

## Stage 0 boundary
- synthetic/mock adapters only;
- ApprovedGateway is mandatory for controlled execution and UNKNOWN_OUTCOME reconciliation;
- precision-aware verified FX is mandatory for cross-currency calculations;
- no prospect contact, publishing, spending, payment collection, or live venture restart;
- unisolated direct connector access means ASSISTED_ONLY, not live autonomy.
