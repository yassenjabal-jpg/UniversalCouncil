# Universal Venture Company — Stage 0

Optional venture operating module around Universal Council v0.3. It does not replace the Council and does not imply a legal company exists.

Default state: PAUSED_BY_OWNER, DRY_RUN, zero live authority.

Core rule: External Reality Supremacy — verified customer behavior, settled money, accepted delivery, and provider state outrank model prose, forecasts, dashboards, or internal consensus.

Stage 0 provides deterministic controls for operation state, grants, operation-scoped capabilities, budgets, actions, evidence/events, obligations, accounting, costs, backup/restore, and synthetic acceptance tests.

No ambiguous CRO role is used. Revenue/Commercial and Risk/Assurance are distinct functions.
