# Universal Venture Company — Stage 0

Optional venture operating module around Universal Council v0.3. It does not replace the Council and does not imply a legal company exists.

Default state: PAUSED_BY_OWNER, DRY_RUN, zero live authority.

Core rule: External Reality Supremacy — verified customer behavior, settled money, accepted delivery, and provider state outrank model prose, forecasts, dashboards, or internal consensus.

Stage 0 provides deterministic controls for operation state, grants, operation-scoped capabilities, budgets, actions, evidence/events, obligations, accounting, costs, backup/restore, and synthetic acceptance tests.

No ambiguous CRO role is used. Revenue/Commercial and Risk/Assurance are distinct functions.

## Company governance overlays
Stage 0 includes mandatory operating overlays for pre-revenue commercial work:
- Distribution & Local Market Fit Gate;
- Zero-Revenue Founder Mode with Forced Conviction;
- HR & Capability Director with Owner-controlled workforce decisions and proactive capability scouting.

These overlays are implemented in config and deterministic validators, not only prose.

## Proactive capability scouting
The HR & Capability Director contains a Technology & Capability Scout function rather than adding another permanent Council role.

It uses event triggers plus a bounded 7-day active / 30-day inactive scan to identify missing or materially improved capabilities across skills, plugins/connectors, tools, evidence channels, automation and testing.

Scouting is read-only by default. Candidate adoption requires provenance/maintenance/permission/data/security/overlap/cost/rollback review, a pinned pilot target, Security and Architecture/Duplication review, Council review, sandbox validation and final Owner adoption authority.

## Market Reality before project generation
Commercial project generation now starts with the Market Reality Definition Gate. The company must define the relevant geography, age + life stage, social/occupational segment, user/buyer/payer, purchasing capacity, buying behavior and evidence locality before a venture candidate is allowed.

Project-first reasoning is treated as a process failure. Both SEGMENT_FIRST and PAIN_FIRST discovery are supported.

## Media venture capability
Media ventures use a venture-scoped production layer with an Editorial Director / Showrunner, AI Visual & Post-Production Producer, and on-demand Audience Growth & Packaging Operator.

A 3-video production pilot is mandatory before scale. Publishing remains separately gated and is not authorized by the media capability layer.
