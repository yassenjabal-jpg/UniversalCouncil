# Evidence and Data

Durable structured records outrank conversation memory. Public Git contains code, policies and synthetic fixtures only.

Evidence stores claim, provenance, observation time, expiry/invalidator, and restrictions. A hash proves identity, not truth.

Capabilities are operation-scoped: for example instagram.publish, instagram.reply, instagram.cold_dm, and payments.settlement. A connector being visible does not prove any one operation is live-ready.

External Reality Supremacy applies whenever model prose, dashboards, forecasts, or internal consensus conflict with verified external state.
