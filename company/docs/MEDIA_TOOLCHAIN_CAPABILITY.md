# Media Toolchain Capability Report

This report defines required media-production capabilities. It does not itself authorize live external actions.

## Capability classes

### Research / source discovery
Status: AVAILABLE_FOR_ASSISTED_WORK
Use: topic research, source discovery, competitive review and factual dossiers.
Boundary: evidence freshness and source-quality rules still apply.

### Script drafting / editing
Status: AVAILABLE_FOR_ASSISTED_WORK
Use: outlines, hooks, scripts, rewrites and editorial alternatives.
Boundary: Editorial Director owns the final creative choice; generated text is not automatically approved copy.

### Image generation / thumbnails
Status: AVAILABLE_FOR_ASSISTED_WORK
Use: concept art, storyboard frames, visual assets and thumbnail concepts.
Boundary: copyright/trademark/personality/public-figure and platform-policy review applies.

### AI video generation
Status: NEEDS_RUNTIME_VERIFICATION
The company must verify a supported generation workflow, output quality, rights/terms and cost before relying on it for the pilot.

### Audio cleanup / mastering
Status: NEEDS_RUNTIME_VERIFICATION
Human narration may be used, but cleanup/mastering capability must be verified before production claims.

### Video editing / assembly
Status: NEEDS_RUNTIME_VERIFICATION
A repeatable edit pipeline must be demonstrated before declaring the venture production-ready.

### Captions / subtitles
Status: CAN_BUILD_OR_VERIFY
Must be checked for timing, Arabic rendering and accuracy.

### Platform publishing
Status: CAPABILITY_GAP
Publishing to YouTube/TikTok/Instagram/Facebook is not authorized or assumed merely because a platform account or connector may exist. Each platform requires a verified capability contract and explicit live authority.

### Analytics ingestion
Status: NEEDS_RUNTIME_VERIFICATION
YouTube/Meta/TikTok analytics access must be verified separately. Manual export is acceptable during early validation if live API access is unavailable.

## Rule
Media readiness is the intersection of:
People Capability × Tool Capability × Rights/Policy Safety × Live Authority.

A zero in any material component blocks the affected live action.

## HR duty
HR & Capability Director maintains this matrix, verifies whether the missing capability can be built/connected, and escalates HUMAN_REQUIRED or unresolved gaps to the Owner.
