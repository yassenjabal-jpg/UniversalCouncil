# Specialist Council Federation Contract

Universal Council can delegate a sub-question to a specialist council.

## Delegation package

- Parent Kernel ID
- Domain question
- Scope
- Evidence already known
- Pivotal unknowns
- Requested output

## Return package

- Specialist decision
- Evidence used
- Domain blockers
- Conditions
- Dissent
- Limitations
- Reopen triggers

## Authority

The Universal Chair may integrate findings but must not silently rewrite or erase a specialist's evidence-backed blocker.

## RevenueSystem adapter

RevenueSystem Council 2.2.1 is the first specialist-council precedent. Its product-specific rules remain in its own repository. Universal Council references it as an external specialist, not as duplicated governance.
