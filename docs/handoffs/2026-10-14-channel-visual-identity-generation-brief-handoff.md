## 2. New candidate visual identity

**Name:** Modern Editorial Surrealism  
**Arabic working name:** السريالية التحريرية المعاصرة

**Primary visual authority:** the user-provided reference video.

Governing Visual Bible:

`docs/operations/media/MODERN_EDITORIAL_SURREALISM_VISUAL_BIBLE.md`

The previous:

`docs/operations/media/EDITORIAL_RENAISSANCE_VISUAL_BIBLE.md`

is marked superseded for current channel visual direction.

### Core visual thesis

> One clear idea, expressed through one memorable visual metaphor, staged like a premium editorial spread.

### Core identity grammar

- editorial clarity;
- strong negative space;
- one hero object/figure;
- episode-specific visual metaphor;
- controlled surrealism;
- contrast between old and new when relevant;
- flat/clean color fields;
- refined typography;
- meaning-driven motion;
- strong episode-level uniqueness.

### Brand anchors

- Electric Cobalt / Azure;
- Paper Ivory;
- Ink Charcoal.

These are anchors, not mandatory dominant colors.

Every episode gets one subject-driven accent.

### Important prohibitions

The channel must not collapse into:
- generic AI cinematic fantasy;
- ancient civilization channel look;
- fixed arches/columns/curtains;
- constant blue + gold + marble;
- tourism poster composition;
- generic ruins/statues;
- same layout + new object + new title.

Architecture is topic-dependent only.

Classical/Renaissance art is optional, not mandatory.

## 3. Reference-video visual findings

The reference video uses:
- saturated cobalt/azure fields;
- nearly white/ivory fields;
- large negative space;
- classical figures used selectively;
- botanical/scientific/object imagery;
- surprising but understandable object relationships;
- elegant editorial composition;
- sparse text;
- print/halftone touches;
- transitions caused by objects or meaning.

Key lesson:

The source identity is not architecture.
It is **editorial staging + visual metaphor + conceptual contrast**.

---

## 4. Thumbnail diversity rules

A thumbnail must belong to the same channel without looking like the previous thumbnail.

Each new thumbnail must materially change at least four of:
- hero object;
- layout family;
- camera/crop;
- dominant field color;
- accent color;
- text position;
- image source type;
- lighting direction;
- texture treatment;
- visual metaphor.

Anti-template rule:

> No more than two major structural devices may carry over from the immediately previous thumbnail.

For each episode, three thumbnail hypotheses are required and should use different image languages:

1. Object Macro
2. Editorial Cutout
3. Conceptual Surrealism

At least one of each three hypotheses must use **zero architecture**, unless architecture is inseparable from the topic.

## 6. Last three generated thumbnails and Council verdict

### A. «كيف وُلدت بغداد؟»

**Verdict:** PASS / strongest result.

Concept:
a hand with a compass draws Baghdad's circular plan while the drawing becomes the city.

Why it worked:
- action-based visual metaphor;
- map/drawing → city transformation;
- negative space;
- different accent color;
- can become motion inside the episode.

Remaining refinements:
- reduce internal city detail;
- make typography slightly more editorial and less dominant.

### B. «كيف تعمل البنوك؟»

**Verdict:** PASS WITH REWORK.

Concept:
a coin enters a mechanism and value emerges on the other side.

Why it worked:
- actual visual metaphor rather than literal bank/vault;
- easy to animate;
- clean ivory field.

Problems:
- machine risks steampunk/AI-default aesthetics;
- house + key narrows the topic toward mortgage lending.

Recommendation:
keep the mechanism metaphor but simplify and broaden the output into credit/value/loan flow rather than a literal house.

### C. «من قرر 24 ساعة؟»

**Verdict:** REBUILD CONCEPT.

Problem:
time topic → sundial is too literal.
The number 24 is also repeated in text/shadow, explaining rather than creating curiosity.

Recommendation:
invent a metaphor that asks **why 24 specifically?**
Examples:
- one familiar circle physically divided into 24;
- an object casting 24 shadows;
- an ancient figure literally trying to divide a day into 24 parts.

Do not simply regenerate a cleaner sundial.

## 7. New structural change — Council-authored generation prompts

A critical process flaw was identified.

Old flow:

Council decision  
→ assistant interprets Council  
→ assistant writes prompt  
→ generation tool

This extra translation layer allowed visual drift.

The adopted new flow is:

Council analysis  
→ Visual Concept  
→ Art Direction  
→ Thumbnail Craft  
→ Synthesis  
→ **Final Visual Generation Brief**  
→ Anti-Slop approval  
→ Technical Operator execution  
→ Anti-Slop output review

### New composed capability

**Name:** Visual Prompt / Generation Brief Compiler

This is NOT a permanent new role/headcount.

Composed by:
- Visual Art Director / Frame Curator;
- Thumbnail & Packaging Designer;
- Synthesis & Alternatives Designer.

Independent approval:
- Red Team / Anti-Slop.

Executor:
- Technical Operator.

---

## 8. Hard generation rules

> **NO PROMPT, NO GENERATION.**

> **NO ANTI-SLOP APPROVAL, NO EXECUTION.**

Additional rules:
- Technical Operator may not creatively rewrite the approved brief.
- Generation tool may not be allowed to materially reinterpret the approved brief.
- Material deviation returns to Council.
- Prompt version + tool/model + execution receipt must be recorded.

The executor is not a creative decision-maker.
