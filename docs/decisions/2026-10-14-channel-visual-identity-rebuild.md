## Decision frame

The previous direction became over-dependent on:
- architectural scenery
- marble/stone
- cobalt + ivory as a fixed composition
- repeated arches/columns
- historical ornament as brand shorthand

This produced recognizable style but insufficient episode differentiation and moved away from the reference video.

## Reference-video finding

The video's visual DNA is:
- strong editorial negative space
- saturated flat color fields
- clean ivory/white fields
- one hero object or figure
- classical/archival imagery used selectively
- contemporary photographic/object imagery
- visual metaphors instead of literal scenes
- old/new juxtaposition
- premium serif-led editorial composition
- restrained print/halftone texture
- object-driven motion

## Council positions

### Design
Identity should live in composition and conceptual contrast, not a permanent set of historical objects.

### Media
The system must survive broad subject changes: economics, science, technology, history, culture.

### Human
Mobile readability requires one dominant silhouette and low visual competition.

### Execution
Cutouts, flat fields, masks, diagrams, object macros, and controlled compositing are practical production primitives.

### Risk
Generated historical-looking scenes must not be presented as documentary evidence.

### Customer Skeptic
Channel recognition must remain strong while the viewer still perceives each episode as a genuinely new story.

### Moat Auditor
The defensible layer is the repeatable method: metaphor selection + editorial composition + motion grammar. A fixed blue/marble/arch template is easily copied.

### Red Team dissent
Red Team rejects any identity implementation that can be reduced to:
`same layout + new object + new title`.

## Synthesis

Adopt **Modern Editorial Surrealism** as the new candidate channel visual system.

Architecture, Greek, Babylonian, Baghdadi, classical, botanical, archival, scientific, or modern motifs are all **topic-dependent tools** rather than mandatory brand markers.

The channel should be recognizable through:
- editorial spacing
- strong visual metaphor
- hero-object hierarchy
- disciplined typography
- controlled color logic
- semantic motion
- episode-specific composition
