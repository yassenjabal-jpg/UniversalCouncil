# Decision — Lock Production System Before Full Video

**Date:** 2026-10-14  
**Owner direction:** stop treating every image as a new design project; prove a repeatable visual production system before attempting an 8+ minute episode.

## Decision

Adopt:

> **Council designs the system → Art Director locks it → Operators produce inside it → Council reviews at gates.**

The Council will no longer act as a full design committee for every ordinary frame once the visual system is locked.

## Required ladder

- P0 — 4–6 coherent reference frames + Visual Production Kit + qualified primary tool.
- P1 — 30–45 second continuous coherence pilot.
- P2 — 60–90 second repeatable production pilot.
- P3 — first 8+ minute episode.

P3 is blocked until P2 passes.

## Authority

Visual Art Director has final visual decision authority **within the locked system**.

Red Team may block drift/slop/evidence-risk but does not replace art direction.

Technical Operator executes; it does not redesign.

Council re-enters at defined gates or material exceptions.

## Tool rule

Primary generation tool must be chosen by a same-frame/same-brief qualification test.

Tool availability, free credits, or remaining balance must not select the channel's primary visual generator.

## Merge

This decision does not authorize merging PR #30 into `main`.
