# ADR-0001 — Universal Council Foundation

## Status
Accepted — initial design

## Context
RevenueSystem Council evolved into a strong domain-specific governance system. A reusable multi-purpose council was requested for decisions and analysis beyond one software project.

## Decision
Create a standalone Universal Council above domain-specific councils.

The foundation uses:
- an eight-role universal core;
- dynamic domain specialists;
- LIGHT / COUNCIL / ARENA modes;
- an explicit evidence hierarchy;
- domain-weighted authority instead of simple voting;
- specialist-council federation;
- external research only when it can change a decision.

## Rejected alternative
Require every existing RevenueSystem role to participate in every topic.

Reason: irrelevant expertise creates noise, repetition and false consensus.

## Consequence
The framework becomes reusable while RevenueSystem Council remains specialized and authoritative in its own domain.
