# Decision — Single-Thumbnail Lock

**Date:** 2026-10-14  
**Scope:** UniversalCouncil media packaging and generated episode thumbnails  
**Owner direction:** focus the Council on generating one thumbnail only instead of three.

## Decision

The previous three-thumbnail-hypothesis requirement is superseded for generated packaging.

The Council may internally discuss or challenge multiple ideas, but the official output for an episode is:

1. **one selected thumbnail concept**;
2. **one Council-authored Visual Generation Brief**;
3. **one Anti-Slop approval**;
4. **one generation job**;
5. **one prompt version**;
6. **one independent thumbnail asset**.

No triptych, diptych, contact sheet, collage, storyboard, multi-panel output, or automatically generated variants are accepted.

If the generated thumbnail fails review, it returns to the Council. The Technical Operator must not generate alternative thumbnails by improvisation.

## Rationale

The three-topic pilot demonstrated that broad generation context encouraged the image runtime to fuse concepts, repeat radial/circular motifs, and optimize for decorative AI composites rather than brief fidelity. Concentrating the full Council on one selected visual metaphor reduces context leakage, prompt drift, template collapse, and visual noise.

## Governing shorthand

> **ONE EPISODE → ONE THUMBNAIL CONCEPT → ONE BRIEF → ONE JOB → ONE ASSET.**

This decision does not authorize merging PR #30 into `main`.
