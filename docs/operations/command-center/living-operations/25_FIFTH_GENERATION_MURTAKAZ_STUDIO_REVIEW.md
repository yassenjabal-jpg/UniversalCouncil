## Decision

The fifth generation is **not approved** as Home / Owner Workspace.

It shows improvement in:
- visible member identities;
- multicolor role treatment;
- curved connection language;
- light theme;
- information density.

However, it remains materially distant from the canonical Home because it changes the screen's composition model.

## What improved

1. Council members are no longer reduced to tiny anonymous generic dots.
2. Roles have stronger individual identity.
3. Multicolor identity is more visible.
4. Routing/connection lines are visually present.
5. The page is information-rich rather than sparse.

These are real improvements and confirm that the member-identity repair was directionally correct.

## Root cause

The existing system had:
- object inventory = WHAT must exist;
- member identity contract = WHO must exist;
- provenance gate = WHICH reference is the parent.

It did **not** yet have a sufficiently strict machine-readable geometry lock for:
- WHERE each major region must remain;
- HOW LARGE it is relative to the canvas;
- WHICH region is visually dominant;
- WHAT order the main sections occupy;
- WHICH transformations are categorically forbidden.

This left enough freedom for the image model to satisfy the inventory while redesigning the page.

## Corrective action

Before any sixth attempt:

1. lock normalized geometry of the canonical Home;
2. lock hierarchy/dominance;
3. lock Council Pulse to horizontal-strip topology;
4. forbid radial-hub reinterpretation;
5. lock product identity;
6. lock rails and bottom dock;
7. require structural-diff evidence after generation;
8. fail candidate before aesthetic review if structure is wrong.

## Final review statement

The fifth attempt demonstrates that the visual vocabulary is moving closer, but **the composition grammar is still not constrained enough**.

Do not build on this candidate.

Fix the geometry contract first.
