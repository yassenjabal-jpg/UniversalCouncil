## Purpose

This contract locks **where the Home objects live and what dominates**.

The object inventory says what must exist.
This file says how the canonical Home is composed.

A future candidate that preserves the objects but changes this geometry is rejected.

## Canvas topology

Canonical desktop topology:

`LEFT STATUS RAIL | CENTRAL OWNER WORKSPACE | RIGHT GLOBAL NAV`

with:
- compact top identity/search bar;
- persistent bottom Tool Dock;
- central workspace stacked vertically.

The central workspace is **not** a radial graph and **not** a node-map-first interface.

## Primary vertical order

Inside the central workspace, preserve this exact macro order:

1. Owner Question / Hero
2. Command Composer
3. Council Pulse
4. Active Work — three project cards
5. Bottom Owner Row — three panels

No other module may become more dominant than the Owner Question + Composer at Home entry.

## Dominance lock

### Dominant
- Owner question;
- Command Composer.

### Strong secondary
- Council Pulse;
- Active Work.

### Supporting
- bottom owner row;
- left operational rail;
- right navigation;
- Tool Dock.

Forbidden:
- giant central owner medallion;
- giant radial Council hub;
- dashboard analytics module becoming the main focus;
- oversized system-health footer.

## Brand lock

## Information truth lock

Generated candidate content must use one of two modes:

### REFERENCE_FIXTURE
Use only reference-observed example content where practical.

### EXPLICIT_PROTOTYPE_FIXTURE
New names/numbers are allowed only when visibly or metadata-labeled as prototype fixture values.

Never imply live CPU/RAM/GPU, live project percentages, verified status, or system health without an explicit fixture/truth label.

## Structural acceptance gate

A candidate fails before aesthetic review if any is true:

- Owner question is not dominant;
- Command Composer is missing or subordinate;
- Council Pulse is not horizontal;
- fewer/more than eight Home member identities are shown in the Pulse;
- owner becomes a giant center hub;
- three Active Work cards are not a major single row;
- bottom owner row is not three distinct sibling panels;
- left status rail missing;
- right global nav missing;
- bottom Tool Dock missing;
- product identity renamed;
- radial/constellation topology becomes the Home's primary composition.
