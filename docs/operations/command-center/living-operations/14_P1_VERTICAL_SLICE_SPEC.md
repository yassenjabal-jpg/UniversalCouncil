# Prototype Phase P1 — Living Project Workspace Vertical Slice

Status: VISUAL DIRECTION CONTINUATION / MURTAKAZ-GATED  
Execution authority: NONE / PROTOTYPE ONLY  
Stage 8: NOT OPENED

## Goal

Prove the adopted Living Operations visual, motion and interaction system in one coherent end-to-end project journey before broad implementation.

P1 is not a production runtime.

It may use explicitly labeled prototype fixtures.

## Primary desktop journey

### Scene 1 — Home command
Owner enters:
"راجع مشروع Smart Secretary V2 وحسن الخصوصية وتجربة الاستخدام."

Visible:
- Command Composer;
- routing mode Auto;
- model;
- reasoning;
- Start.

### Scene 2 — Project opens
Living Project Workspace becomes primary.

Show:
- Project Core;
- Autopilot RUNNING;
- stage rail;
- latest checkpoint;
- adaptive software center;
- Tool Dock;
- Filmstrip.

### Scene 3 — Role activation
Activate:
- Evidence;
- Human/UX;
- Red Team.

Required:

### Scene 4 — Evidence
Evidence produces a prototype artifact.

Show:
- artifact enters Filmstrip;
- truth = EVIDENCE-BACKED;
- Evidence Peek accessible.

### Scene 5 — Handoff
Artifact moves from Evidence/analysis to UX/revision stage.

Required:
- M3 motion;
- source/destination clear;
- artifact clickable during/after final state.

### Scene 6 — Revision
Filmstrip gains:
- Before;
- UX Revision;
- Red Team Return;
- Revision 2.

Click each frame -> Version Inspector.

### Scene 7 — Owner Decision
Red Team raises material privacy objection.

Autopilot -> WAITING_OWNER.

Enter Decision Mode:
- recommendation;
- strongest dissent;
- evidence summary;
- approve/reject impact.

### Scene 8 — Decision result
Owner chooses Request Changes.

Decision resolves to history.

Do not resume Autopilot until separate prototype event is emitted.

### Scene 9 — Checkpoint + recovery
Simulate tool failure.

Autopilot -> RECOVERING.

Show:
- current stops;
- last verified checkpoint;
- bounded rewind;
- restored verified event;
- resumed state.

### Scene 10 — Fork
Owner selects checkpoint and creates:
- Branch A — privacy-first;
- Branch B — richer automation.

Show:
- branch split;
- Branch Inspector;
- compare state.

### Scene 11 — Branch decision
Compare:
- tests;
- privacy;
- UX;
- performance;
- evidence.

Owner selects A.

### Scene 12 — Completion
Emit `PROJECT_COMPLETED_VERIFIED`.

Show:
- rail settles;
- final artifacts gather;
- Work Receipt.
