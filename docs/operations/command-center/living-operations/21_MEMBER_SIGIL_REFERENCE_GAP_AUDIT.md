# P1 — Member / Role Sigil Reference Gap Audit

Date: 2026-10-20  
Status: CORRECTION AUDIT / MURTAKAZ-GATED  
Scope: canonical references vs. rejected composite generation

## 1. Finding

The latest generated composite drifted materially from the canonical visual system.

The problem was not limited to spacing or styling. It removed a major product identity layer: the Council/Studio members as interactive, stateful visual objects.

Generation classified as rejected drift:

`79110079-3684-437e-9c29-825ac3f6cb4d`

It must not be reused as a visual source.

## 2. What the canonical references actually contain

### Home / Owner Workspace

The canonical Home shows eight Council Pulse member identities:

- المالك;
- الاستراتيجية;
- البحث;
- التحقق;
- التنفيذ;
- الإبداع;
- البيانات;

Each is a colored circular medallion with:

- a distinct glyph;

- its own identity tint;
- routing/connection paths;

Project cards also contain compact clusters of participating member medallions.

They are connected by colored dotted/curved routing paths and carry operational state/truth markers.

This is a working-member graph, not decorative iconography.

- الأدلة;

## 3. Missing interaction layers in the rejected generation

The governing source requires:

- hover -> role/function tooltip;
- click -> Role Context;
- Enter/Space -> same action;
- visible focus;
- reasoning rings -> Model & Reasoning Inspector;
- Role Context -> why active, task, state, findings, dissent, evidence, model/reasoning, recent contributions;
- event-backed activation/state motion;
- blocker/completion truth behavior;
- Reduced Motion equivalent.

The rejected generation communicated none of this faithfully.

## 4. Major visual losses in the rejected generation

Compared with the canonical Home, it removed or materially simplified:

- the eight-member Council Pulse identity system;
- reference glyphs and role subtitles;
- routing paths between members;
- member state/reasoning layers;
- compact participant clusters on project cards;
- the exact left operational/status rail;
- the full Command Composer control density;
- three substantial Active Work cards;
- the distinct lower panels for updates / decisions / results;
- the persistent bottom Tool Dock;
- the reference's information density and artifact detail.

It also introduced an unsupported member label, **المعمارية**, which is not part of the canonical Home member set and contradicts the reference-only lock.

## 5. Root cause

The previous visual step used a simplified textual reconstruction rather than treating the canonical image as the literal parent composition.

That allowed semantic compression:

member identity -> generic icon  
routing graph -> decorative spacing  
interactive layers -> static symbols  
dense operational Home -> simplified dashboard

This is prohibited going forward.

## 6. Corrective rule

For every flagship screen:

1. identify the exact canonical parent;
2. inventory every visible semantic object;
3. inventory every member/Sigil and its role;
4. inventory every routing path, badge, state and action;
5. inventory interaction destinations;
6. only then authorize a bounded artifact job.

No screen may be regenerated from a short summary of its layout.

## 7. Home artifact repair requirement

`P1-HOME-ARTIFACT-001` remains unapproved.

Any replacement candidate must preserve the full eight-member Council Pulse system and all reference-observed Home regions before aesthetic review begins.

The rejected composite cannot be used as a parent, moodboard, reference, or derivative source.
