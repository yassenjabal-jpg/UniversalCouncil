## Evidence rule

Major UX structural decisions must state:
1. observed problem;
2. affected operator/task;
3. measurable cost or risk;
4. proposed correction;
5. alternative considered;
6. expected benefit;
7. regression risk;
8. runtime validation method.

Taste-only vetoes are prohibited.

## Major-screen review protocol

1. UX brief
2. Three structural layouts: Efficiency-first / Balanced / Identity-first
3. Cognitive walkthrough
4. Council + Studio red-team
5. Representative synthetic runtime
6. Quantitative UX scorecard
7. UX runtime acceptance
8. Art Director visual expression
9. Independent Visual QA
