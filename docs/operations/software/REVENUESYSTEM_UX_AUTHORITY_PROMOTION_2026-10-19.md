# RevenueSystem 2.0 — UX Authority Promotion Decision
Date: 2026-10-19
Status: OWNER APPROVED / ACTIVE IMMEDIATELY

## Decision

The RevenueSystem UI/UX Interaction Architect is promoted to:

**RevenueSystem Chief UX & Interaction Authority**

This role is now the **primary and highest design authority** for all decisions involving:

- usability;
- workflow simplification;
- screen-space efficiency;
- title-bar and chrome density;
- information hierarchy;
- navigation;
- keyboard-first operation;
- focus order;
- interaction flow;
- operator speed;
- long-session ergonomics;
- cognitive load;
- error prevention.

## Design precedence

1. RevenueSystem Chief UX & Interaction Authority
2. RevenueSystem Visual Art Director
3. RevenueSystem WPF Design Systems / Visual Engineering Lead
4. Independent Visual QA / Reference Fidelity Reviewer

The Visual Art Director remains responsible for artistic quality and the Editorial Financial Engraving identity, but must work inside the layout, density, hierarchy and workflow constraints approved by the Chief UX & Interaction Authority.

If a decorative, branding or art element consumes excessive space, slows the operator, duplicates information, harms keyboard flow, or increases cognitive load, the UX authority may require its reduction, relocation or removal even if the Art Director prefers to retain it.

## Mandatory UX pre-clearance

No major RevenueSystem design modification may proceed to visual polish before UX pre-clearance for:

- shell chrome;
- title bars;
- workspace headers;
- hero bands;
- sidebars;
- inspectors;
- navigation;
- input density;
- keyboard flow;
- dialogs/popups;
- long-session workspaces.

The UX authority also performs a runtime review after implementation and before Art Director final clearance.

## Hard constraints

UX authority does not override:

- financial/domain truth;
- data integrity;
- security controls;
- accessibility minimums;
- architecture boundaries;
- owner authority.

When a conflict involves those constraints, the corresponding Council specialist may block the design.

## Current immediate implication

The 2026-10-19 horizontal chrome/title-bar finding is now treated as a UX-authority issue.

The current recommendation to:
- remove the dedicated 42px WorkItemTabs strip;
- merge active-workspace information into a single context ribbon;
- compress shell/header heights;
- return reclaimed vertical space to the financial task;

is elevated from a normal design recommendation to a **mandatory UX correction before Section 1 art-fidelity re-lock**.
