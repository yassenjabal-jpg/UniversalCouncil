# Visual Production System — Lock Before Scale

**Status:** GOVERNING for the media pilot  
**Decision date:** 2026-10-14  
**Core principle:** Council designs the system → Art Director locks it → Operators produce inside it → Council reviews only at gates.

## 1. Why this system exists

The thumbnail pilot exposed a structural failure: too much creative decision-making was happening during execution. A single asset repeatedly reopened questions of style, metaphor, tool choice, palette, and composition. That cannot scale to an 8+ minute documentary.

The fix is to separate:
- **system design** from **shot production**;
- **gate review** from **frame-by-frame committee review**;
- **tool qualification** from **tool availability**.

## 2. Authority model

### Council
Before lock:
- challenge identity;
- compare alternatives;
- define quality bars;
- approve the production system.

After lock:
- review only at defined gates;
- do not redesign ordinary frames;
- reopen the system only for a material exception.

### Visual Art Director / Frame Curator
Inside a locked visual system:
- owns final frame-level visual decisions;
- locks palette/type/grid/texture/shadow/image-treatment rules;
- approves normal frame variations;
- resolves visual ambiguity without returning every frame to the full Council.

### Red Team / Anti-Slop
- may block brand drift, AI slop, evidence confusion, or reference-fidelity failure;
- does not become a second Art Director;
- sends material failures back to the Art Director/system gate.

### Technical Operator
- chooses only qualified/authorized execution routes;
- executes approved artifacts;
- cannot creatively rewrite the locked visual language.

## 3. P0 — Visual System Lock

Do not begin a real episode yet.

Produce **4–6 coherent reference frames from one topic** covering the useful production language. The target set should include, when relevant:
1. Hero Question;
2. Object Macro;
3. Evidence / Archive treatment;
4. Diagram / Mechanism;
5. Editorial Cutout;
6. Conceptual Surrealism.

The set passes only if the frames:
- clearly belong to one channel;
- are materially different from one another;
- preserve Modern Editorial Surrealism;
- avoid template collapse;
- demonstrate how real evidence and illustration coexist;
- can plausibly be animated or edited into a sequence.

### P0 deliverable: Visual Production Kit

Use:
`docs/templates/media/VISUAL_PRODUCTION_KIT.md`

Lock:
- palette;
- typography;
- grid;
- negative-space rules;
- texture;
- shadow behavior;
- image-source treatments;
- frame families;
- diagram language;
- transition grammar;
- motion rules;
- anti-slop rules.

P0 cannot pass until the primary image-generation route has passed Tool Qualification.

## 4. P1 — 30–45 second coherence pilot

Build a continuous **30–45 second** sequence from one real episode concept.

It must include:
- temporary or owner narration;
- roughly 6–10 visual beats;
- designed transitions;
- temporary/approved music;
- sound design;
- at least one genuine evidence/archive visual;
- at least one explanatory visual;
- at least one breathing/reset moment when pacing needs it.

P1 asks one question:

> Can this identity remain coherent through time, not just inside one pretty still?

### P1 gate
Council reviews the sequence as a system demonstration, not each frame as an isolated artwork.

Pass criteria:
- coherent visual grammar;
- no abrupt style resets;
- understandable visual hierarchy;
- motion generated by meaning;
- narration/picture relationship works;
- audio supports rather than decorates;
- evidence remains distinguishable from illustration;
- operator can execute without constant Council intervention.

## 5. P2 — 60–90 second production pilot

Only after P1 passes, build **60–90 seconds**.

This stage tests the production workflow, not merely the look.

Required:
- locked Visual Production Kit;
- repeatable asset naming/versioning;
- stable toolchain;
- narration → visual beats → motion → audio workflow;
- evidence/explanation/atmosphere balance;
- realistic rework loop;
- operator can complete ordinary frames without full-Council review;
- Art Director can keep visual continuity across many shots.

P2 must prove that the process is repeatable.

## 6. P3 — 8+ minute episode

A full documentary of at least **480 seconds** is blocked until P2 passes.

The first full episode is not the place to discover:
- the channel's typography;
- basic palette rules;
- which image model follows prompts;
- how evidence is treated;
- how transitions behave;
- who has final visual authority.

Those are P0–P2 questions.

## 7. Council review gates after lock

The full Council reviews at:
1. Visual System Lock;
2. P1 review;
3. P2 review;
4. Animatic;
5. Picture Lock;
6. Final QC.

Do not require full-Council approval for ordinary frame creation after visual lock.

### Exception triggers
Return to Council only for:
- material brand drift;
- evidence/rights risk;
- Anti-Slop failure that cannot be resolved within the locked system;
- a genuinely new visual language not covered by the kit.

## 8. Scaling test

The system is working when:
- later frames take less decision time than early frames;
- tool prompts become shorter because the production kit carries the language;
- normal frames do not trigger a Council debate;
- the Art Director can approve or correct work quickly;
- operators can reproduce the visual grammar;
- P1 and P2 look like one film rather than a sequence of unrelated AI images.

## 9. Failure signal

If a 30-second sequence still requires:
- redesigning the identity per shot;
- changing the primary generation tool repeatedly;
- Council votes on ordinary composition;
- repeated prompt rebuilding from scratch;

then P0 has not passed and full production stays blocked.
