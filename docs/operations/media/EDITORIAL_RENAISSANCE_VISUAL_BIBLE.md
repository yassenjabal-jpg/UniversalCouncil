# Editorial Renaissance Motion — Visual Bible v1

## Purpose

Create a recognizable visual world across unrelated topics without turning videos into a repeated template.

## Palette

Core:
- Cobalt #174FA6
- Clear Blue #2B73C9
- Sky Blue #8EACD2
- Paper Ivory #F6F1E8
- Warm Parchment #D9C8B1
- Deep Forest #173C32
- Brass / Gold #B58A3E
- Charcoal #151515

Rule:
Each episode may add one accent color, but core palette remains dominant.

## Typography

Arabic display:
editorial Naskh / refined serif-like Arabic.

Arabic body:
clean contemporary sans.

Latin display:
high-contrast editorial serif.

Latin body:
neutral modern sans.

Fallback families:
Noto Naskh Arabic, IBM Plex Sans Arabic, Cormorant Garamond/Fraunces, Inter.

## Grid

- 16:9 master.
- safe margins 6% horizontal / 7% vertical.
- editorial frames use 35–55% negative space.
- one hero object per frame.
- one main headline maximum.
- one micro-caption maximum.
- avoid bottom-third news graphics.

## Texture

Allowed:
paper grain, print imperfections, engraving hatch, subtle film grain.

Not allowed:
heavy fake VHS/glitch unless narratively justified.

## Image language

Preferred:
- classical/Renaissance figures as cutouts;
- botanical/scientific engravings;
- archival documents;
- clean modern photography;
- diagrams/maps;
- object macros;
- typography as composition.

AI-generated images:
- must obey palette/lighting/composition brief;
- cannot replace evidence;
- cannot fabricate a real event as if documentary evidence;
- realistic synthetic content gets disclosure review.

## Canonical frame families

F01 Hero Question:
one arresting object/figure + minimal question.

F02 Evidence Document:
source fragment / document / date / highlighted evidence.

F03 Editorial Portrait:
person + negative space + one context label.

F04 Scientific Engraving:
illustrated mechanism / natural form / historical diagram.

F05 Mechanism Diagram:
cause→effect, flow, system nodes.

F06 Number / Scale:
one number, one visual comparison.

F07 Map / Spatial:
where / movement / distance / boundary.

F08 Object Macro:
one familiar object shown as a portal to the hidden story.

F09 Historical Collage:
archive + classical figure + map/document.

F10 Modern Reality:
photo/video grounded in contemporary life.

F11 Breathing Reset:
cobalt/ivory sparse frame, low narration density.

F12 Ending Reflection:
visual echo of opening transformed by what viewer learned.

## Motion grammar

Use:
- object wipes;
- masks;
- match cuts;
- diagram extraction;
- zoom-through-object;
- parallax;
- page shifts;
- line-drawing builds;
- foreground occlusion;
- color/shape matches;
- cobalt reset frames.

Motion timing:
- explanatory motion follows narration meaning;
- hero reveals may precede narration by 4–12 frames;
- labels appear after viewer sees object;
- do not animate every element simultaneously.

## Transition design

Every transition has:
FROM frame ID
TO frame ID
semantic link
visual link
motion direction
duration
sound cue
fallback cut

If no reason exists, use a clean cut.

## Episode uniqueness rule

Before production define:
- 3 episode-specific visual motifs;
- 1 hero object;
- 1 recurring diagram language;
- 1 unique transition motif.

These cannot be copied wholesale into the next episode.

## AI-slop visual test

Ask:
1. Could this frame appear unchanged in another episode?
2. Does it explain anything?
3. Is it merely beautiful?
4. Is the same generated composition repeated?
5. Is there a source/evidence relationship?
6. Does the transition carry meaning?

If answers trend toward generic beauty, reject.
