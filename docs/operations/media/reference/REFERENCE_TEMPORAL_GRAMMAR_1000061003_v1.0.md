## 1. Core finding

The reference does **not** maintain identity by repeating one material, one composition, one color field, or one image type.

It maintains identity by keeping a **single conceptual subject/object thread** while transforming that thread across different media, scales, textures and editorial treatments.

In the reference, the pear idea migrates through:
- classical figure;
- fabric/macro transition;
- organic strip/branch;
- real botanical process;
- orchard photography;
- classical/editorial portrait;
- hand/object interaction;
- cobalt field;
- halftone/dither;
- construction photography;
- drawing/blueprint;
- sculptural golden object;
- premium editorial spread;
- final figure/botanical scene.

Therefore:

> **CHANNEL CONTINUITY = EDITORIAL GRAMMAR + EPISODE MOTIF TRANSFORMATION, NOT REPEATED MATERIAL.**

For DAY24 v2, the recurring episode motif should be **division / segment / boundary / unit**, not “paper.”

## 6. Color grammar

### Structural anchor
**Electric cobalt / azure**
- used as a reset field;
- creates immediate brand recognition;
- supports typography and cutouts;
- returns after visually dense passages.

### Neutral anchor
**Paper ivory / off-white**
- hosts cutouts, drawing, sculpture, editorial pages;
- provides breathing space.

### Contrast anchor
**Ink charcoal / black**
- typography;
- structural lines;
- dark fabric/object framing.

### Episode/source color
Natural green, warm brass/gold, skin, plant color, image-specific hues.

### Correction to Production Kit v1.0
Cobalt is no longer merely “optional.”
It is a **recurring structural anchor**, while not required in every frame.

## 7. Typography grammar

Observed reference behavior:
- one large editorial display statement;
- tiny supporting information;
- type can be the dominant subject;
- type placement changes per composition;
- serif/display typography creates premium editorial contrast;
- text participates in pacing.

### Retry rule
A 35–45 s pilot must contain at least:
1. hook typography beat;
2. explanatory fact/number beat;
3. closing synthesis beat.

Typography must be deterministic and animated as part of picture design.

## 8. Motion grammar

Every authored shot must define:

1. **ENTRY STATE**
2. **ACTIVE EVENT**
3. **EXIT STATE**
4. **NEXT-SHOT CONNECTION**
5. **AUDIO CUE**

A shot is not production-ready if it only defines a still composition.

### Preferred motion sources
- human interaction;
- object manipulation;
- line growth;
- material sweep;
- crop/scale transformation;
- drawing construction;
- color-field takeover;
- typography reveal/re-layout;
- botanical motion;
- shape match.

### Avoid
- generic Ken Burns as primary motion;
- random camera moves;
- default dissolve as main transition language;
- identical parallax on every shot.
