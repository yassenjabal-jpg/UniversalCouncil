## 1. Identity

Channel visual system:
**Kinetic Editorial Surrealism**

Operational definition:

> Mixed-media editorial composition linked through episode-specific motif transformation, deterministic typography, strong negative space, cobalt/ivory structural fields, human/object interaction, real evidence, diagrams and object-caused transitions.

Continuity comes from:
- editorial hierarchy;
- palette discipline;
- transition causality;
- motif transformation;
- typography;
- motion timing.

Continuity does **not** come from repeating one material such as paper/card.

For DAY24 the continuity motif is:
**division / segment / boundary / unit**.

## 2. Color

### Structural anchors
- Electric Cobalt/Azure: approx. `#0F57AE–#1B79C9`
- Paper Ivory: approx. `#F2EFE8`
- Ink Charcoal: approx. `#1D1B1A`

### Episode accent
DAY24:
- deep plum / mineral red;
- normally <10% frame area.

### Rules
- cobalt must recur meaningfully as a structural reset field;
- cobalt is not required in every shot;
- neutral/photographic source colors remain source-appropriate;
- no blue+gold+marble luxury shorthand;
- no neon default.

## 3. Typography

### Arabic
Preferred production direction:
- display: **Noto Kufi Arabic Bold/SemiBold**
- body/labels: **Noto Sans Arabic Regular/Medium**

### Latin / numerals
Preferred:
- **Source Serif 4** for editorial contrast.

### Runtime fallback
If preferred fonts are unavailable during prototype work:
- use a legible Arabic-capable system font only as TEMP;
- final picture lock requires an explicit font lock.

### Rules
- image models never render final Arabic text;
- typography is authored deterministically in AE/design tools;
- type may be a primary visual subject;
- key beats may combine one display statement + restrained micro-copy;
- no dense caption wall;
- animation timing must serve meaning.

DAY24 retry requires at least:
1. hook typography;
2. explanatory fact/number;
3. closing synthesis.

## 4. Grid and hierarchy

- base grid: 12-column editorial grid;
- negative space: normally 35–60%;
- one dominant focal idea;
- asymmetry preferred;
- subject may cross frame boundaries;
- aggressive macro crops allowed;
- alternate wide / medium / extreme-macro scales;
- no filler objects added merely to “make it richer.”

## 5. Media families

Approved:
1. cobalt/ivory graphic field;
2. real evidence/archive;
3. modern photography/cutout;
4. human hand/action;
5. vector/diagram;
6. line drawing/technical plan;
7. halftone/dither;
8. sculptural/2.5D object;
9. macro photographic/material texture;
10. historical painting/engraving when relevant and sourced.

### Diversity rule
For a 35–45 s pilot:
- >=4 meaningful families;
- target 5–7 when useful;
- max 2 consecutive beats with the same dominant family;
- no single material becomes the identity;
- paper/card may not dominate >40% of runtime.

## 6. Source treatment

### Evidence
Evidence pixels remain source-faithful.

Allowed:
- crop;
- scale;
- mask;
- mount;
- deterministic labels;
- external lines/markers.

Forbidden:
- generative rewriting;
- fabricated missing areas;
- altering people/inscriptions/content;
- synthetic archive presented as evidence.

### Photography
- disciplined cutout/crop;
- editorial integration via field, mask, type, print texture;
- avoid glossy product-ad styling by default.

### Generated conceptual visual
- explanation/atmosphere only;
- one metaphor;
- one hero;
- never impersonates documentary evidence.

## 7. Texture

Texture changes with medium:
- subtle paper grain;
- photographic grain;
- halftone/dither;
- drawing/ink texture;
- fabric/material macro;
- clean digital field.

No universal “premium paper” overlay.

## 8. Lighting

For generated/conceptual objects:
- soft directional studio light;
- restrained shadow;
- material legibility over spectacle.

Avoid:
- volumetric haze;
- sunset drama;
- luxury glow;
- glossy ad lighting unless narratively justified.

## 9. Motion-first shot contract

Every production shot must define:

1. **ENTRY STATE**
2. **ACTIVE EVENT**
3. **EXIT STATE**
4. **NEXT-SHOT CONNECTION**
5. **AUDIO CUE**

A still composition without those fields is not production-ready.

## 10. Motion grammar

Preferred:
- human/object reveal;
- macro material bridge;
- shape match;
- process→result scale expansion;
- object match across media;
- split/reveal;
- blur/dither/halftone transformation;
- drawing→object;
- process→editorial layout;
- cobalt/ivory field reset;
- line/groove build;
- evidence insertion;
- photo→diagram extraction.

Avoid:
- generic dissolve as primary grammar;
- preset wipe packs;
- random whip pan;
- glitch without narrative reason;
- uniform Ken Burns across stills;
- camera movement with no semantic function.

## 11. Rhythm

Reference-derived target:
- active section: meaningful visual event every 0.8–1.5 s;
- transition micro-beat: 0.3–0.8 s;
- intentional breathing beat: 2–3 s max with internal motion;
- unchanged static frame >3 s: reject unless approved exception.

This is authored evolution, not frantic cutting.

## 12. Diagram language

- charcoal lines;
- one episode-color marker;
- deterministic counts;
- exact geometry;
- native vector builds preferred;
- arrows only when causality requires them;
- no dashboard/HUD look;
- no AI-generated numbers/text.

DAY24 exact count:
24 visible divisions must be native/deterministic.

## 13. Human interaction

Human/action beats are encouraged when they:
- create scale;
- create causality;
- trigger a transition;
- clarify a physical metaphor.

Preference:
1. real/credible photography;
2. sourced archival figure when evidentially relevant;
3. generated contemporary figure only when clearly illustrative.

Generic mannequin look is not a brand motif.

## 14. Transition contract

The outgoing shot must supply meaningful geometry/material/action to the incoming shot.

If two shots do not connect:
- redesign the pair;
- do not conceal mismatch with a generic dissolve.

## 15. Audio-visual design

Sound is designed with picture.

Spot:
- object contact;
- line build;
- material pull;
- archive placement;
- diagram snap;
- fold/shape transition;
- color reset;
- closing resolve.

Avoid:
- clock ticking by default;
- swoosh on every cut;
- generic trailer riser;
- constant wall-to-wall accents.

Final mix target remains:
- approx. -14 LUFS ±1;
- <= -1 dBTP;
- dialogue clearly dominant.

## 16. Anti-Slop lock

Reject:
- repeated paper-object template;
- repeated circle/radial template across unrelated topics;
- fake archive;
- generated Arabic text;
- architecture/classical art without narrative reason;
- blue/gold/marble default;
- generic gears for systems;
- multiple unnecessary focal objects;
- cinematic fantasy replacing explanation;
- static slideshow logic;
- transitions unrelated to scene content.
