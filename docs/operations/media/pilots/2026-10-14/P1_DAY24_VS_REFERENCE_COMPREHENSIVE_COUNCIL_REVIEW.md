## 0. Important interpretation boundary

The supplied reference is a vertical TikTok/screen recording of a monitor showing the actual visual work. The Council evaluates the **visual content shown on the monitor**, not:
- TikTok UI;
- the phone/screen-recording wrapper;
- the black overlay caption;
- the physical monitor/desk.

The duplicated library uploads of the reference were verified byte-identical, so the review is anchored to the intended reference rather than memory.

## 1. Executive conclusion

P1 solved **consistency**, but it solved the wrong level of the problem.

What P1 successfully proved:
- multiple frames can share one palette and material language;
- generated conceptual imagery can coexist with real evidence;
- a 41.77-second narration spine can be assembled without reopening identity decisions per frame.

What P1 did **not** prove:
- the kinetic editorial energy of the reference;
- mixed-media richness;
- object-driven continuity;
- integrated editorial typography;
- frequent but controlled visual transformation;
- audiovisual accenting;
- professional compositing/finishing.

The P1 sequence currently reads as:

> a coherent premium editorial slideshow made from still concept images

while the adopted reference reads as:

> a kinetic mixed-media editorial world in which objects, photography, type, texture, drawings, human interaction and transitions continuously transform into one another.

That is the central gap.

## 2. Quantitative delta

### 2.1 Visual event density

Frame sampling of the visible reference content shows roughly **15 materially distinct visual states within the first ~14.5 seconds**.

Approximate reference event density:
- ~1 significant visual state / **0.9–1.1 s**

P1:
- 8 principal visual states across **41.77 s**
- ~1 state / **5.2 s**

Therefore P1 is approximately **5× slower in meaningful visual-event density**.

This does **not** mean the retry should become frantic. It means static holds must be replaced by internal motion, transformations, reveals and shot evolution.

### 2.2 Audio loudness

Measured supplied reference:
- integrated loudness: approx. **-14.2 LUFS**
- true peak in the social recording reaches **0.0 dBFS**

Measured revised P1:
- integrated loudness: **-25.5 LUFS**
- true peak: **-10.6 dBFS**

P1 is therefore about **11.3 LU quieter** than the supplied reference recording.

The reference file is not a clean mastering source, so its 0 dBFS peak is **not** a delivery target. But its perceptual energy is materially stronger.

Retry target:
- integrated program: **-14 to -16 LUFS**
- true peak: **<= -1 dBTP**
- narration always intelligible.

### 2.3 Audiovisual accent density

The supplied reference waveform contains pronounced energy/transient events close to multiple visible changes around approximately:
- 3.25 s
- 6.25–7.25 s
- 8.0–9.0 s
- 11.25 s
- 12.75–13.0 s
- ~15.0 s

Because the source is a TikTok/screen recording, these are treated as qualitative evidence, not a clean mix map.

P1 uses only three intentionally placed SFX anchors (~5, ~17, ~36 s), leaving most visual changes acoustically unarticulated.

## 3. Reference grammar observed by the Council

### 3.1 Composition
The reference uses:
- asymmetrical editorial layouts;
- large negative space;
- subjects breaking frame boundaries;
- aggressive macro crops;
- rapid shifts between close, medium and wide scales;
- clean full-color fields alternating with textured image-rich frames.

P1:
- uses negative space well;
- but too many frames share a similar mid-wide “object on ivory field” product-photo composition.

### 3.2 Color
Reference:
- strong recurring electric cobalt/azure field;
- off-white / paper neutral;
- black/charcoal;
- subject-driven greens, warm skin, gold/brass pear;
- high contrast between saturated and neutral scenes.

P1:
- ivory and charcoal are coherent;
- blue is too muted and too optional;
- deep plum accent is controlled but visually weak;
- overall palette becomes beige/blue-gray for too long.

**Required correction:** Electric cobalt becomes a recurring structural field, not merely an optional accent.

### 3.3 Mixed-media language
Reference visibly moves among:
- editorial typography;
- classical/figurative imagery;
- modern photography;
- hands / human interaction;
- botanical imagery;
- textured macro material;
- line drawing / technical illustration;
- halftone/dither treatment;
- sculptural / 3D object;
- architectural/build process imagery;
- full color fields.

P1 relies overwhelmingly on:
- AI-generated tactile paper/card objects;
- one raw evidence image;
- one generated paper-cut human.

**Required correction:** paper is one medium in the toolkit, not the identity itself.

### 3.4 Typography
Reference:
- typography is part of the composition;
- large elegant headline blocks coexist with tiny editorial information;
- text alternates between being focal and secondary;
- typography participates in rhythm.

P1:
- almost no authored editorial typography;
- evidence credit appears, but typography is not a visual-system actor.

**Required correction:** deterministic Arabic typography must appear in designed key beats, not merely captions/source labels.

### 3.5 Motion
Reference:
- subjects move inside frames;
- fabric/objects cause reveals;
- crops change meaning during the shot;
- forms enter/exit the frame;
- action continues through transitions;
- transitions often emerge from the object itself.

P1:
- hard cuts;
- limited Ken Burns;
- still-image holds.

**Required correction:** every shot is authored as a motion shot with:
1. entry state;
2. active state;
3. exit state;
4. connection to the next shot.

### 3.6 Transition grammar
Reference examples observed:
- curtain/fabric reveal;
- macro surface/strip used as a bridge;
- object/shape match;
- blur/dither transition;
- human-hand interaction;
- image-to-color-field reset;
- line/drawing-to-object relationship;
- scale/match transitions.

P1:
- mostly hard cuts independent of scene content.

**Required correction:** transitions must be designed before final assets are produced.

### 3.7 Texture
Reference:
- dither/halftone;
- photographic grain;
- fabric;
- botanical texture;
- drawing/print;
- clean digital field;
- sculptural surface.

P1:
- paper grain repeated too uniformly.

**Required correction:** texture must change with source medium while remaining under one art direction.

### 3.8 Human presence
Reference:
- people/hands make objects feel acted upon;
- human interaction creates transitions and scale.

P1:
- F5 mannequin/cutout looks synthetic and illustrative in the least refined way.

**Required correction:** generated mannequin figure is prohibited as a recurring device.
Preferred:
1. real licensed contemporary photography;
2. real archive/painting when historically valid;
3. high-quality clearly illustrative generated figure only when necessary.

### 3.9 Evidence treatment
P1 strength:
- real Met evidence was preserved.

P1 weakness:
- the Met image appears as a comparatively raw rectangular insert and visually steps outside the richer reference grammar.

**Required correction:** evidence remains source-faithful but is integrated via:
- authored crop;
- editorial mount;
- typography;
- controlled cobalt/ivory surrounding field;
- line/diagram extraction outside the evidence pixels;
- animated entry/exit.

Never generatively rewrite the evidence itself.

### 3.10 Audio / sound
Reference:
- much higher perceived energy;
- frequent audiovisual accenting;
- changes feel authored in rhythm.

P1:
- narration is a spine;
- music and three SFX exist;
- but sound does not participate in most transitions;
- total level remains too low.

**Required correction:** create an audio spotting sheet before final assembly.

## 4. Council role-by-role review

### Visual Art Director
**Verdict: FAIL against reference fidelity**

Keep:
- negative space;
- disciplined hierarchy;
- conceptual clarity;
- ivory/charcoal base.

Change:
- stop treating premium paper/card as the channel’s dominant universal material;
- bring cobalt back as a structural anchor;
- require mixed-media variation;
- author typography as a graphic element;
- increase crop/scale variety.

### Motion & Picture Editor
**Verdict: MAJOR FAIL / principal bottleneck**

Main defect:
P1 is a sequence of stills, while the reference is a sequence of evolving visual events.

Correction:
build a transition graph and motion beats before generation/compositing.

### Thumbnail & Packaging Designer
**Verdict: PARTIAL**

The P1 hero can work as one isolated graphic, but long-form identity cannot be derived from thumbnail logic.

Correction:
separate thumbnail composition rules from temporal scene rules.

### Evidence & Research Lead
**Verdict: PASS boundary / PARTIAL presentation**

Evidence integrity is correct.
Presentation must be more editorial and integrated without altering source truth.

### Music & Sound Supervisor
**Verdict: FAIL against reference energy**

Correction:
music structure + transient accents + material Foley must be mapped to visual beats.

### Dialogue / Mix Engineer
**Verdict: FAIL delivery level**

P1 revised mix:
-25.5 LUFS / -10.6 dBFS peak.

Correction:
proper gain staging and final normalization in a qualified audio route.

### Red Team / Anti-Slop
**Verdict: FAIL due template collapse risk**

The system avoided obvious “AI fantasy slop,” but created a new failure mode:
**premium-paper template slop**.

Symptoms:
- repeated ivory field;
- repeated tactile object;
- repeated studio shadow;
- repeated centered product-object logic.

Correction:
system coherence must come from editorial grammar, not repeated material.

### Media Producer
**Verdict: workflow redesign required**

The process optimized independent still generation and only later attempted to animate them.
That sequence is backwards for this reference.

New rule:
**motion design precedes final asset production.**

## 6. Root causes

1. **We locked still-frame identity before fully deconstructing temporal identity.**
2. **We overfit the first thumbnail/object metaphor into the channel language.**
3. **We generated independent frames instead of linked motion states.**
4. **The Production Kit described motion, but the actual toolchain could not execute it.**
5. **We accepted Descript as a temporal assembly tool beyond its appropriate role.**
6. **Typography was treated as a later overlay rather than part of art direction.**
7. **The reference’s mixed-media diversity was simplified into one tactile-paper material.**
8. **Audio spotting came after edit construction rather than helping design the edit.**
9. **The review gate asked “is it coherent?” instead of also asking “is it faithful?”**

## 7. Governing corrections for retry

### G1 — Two independent gates
Every future pilot must pass:
1. **INTERNAL_COHERENCE**
2. **REFERENCE_FIDELITY**

Neither substitutes for the other.

### G2 — Motion-first shot design
No final visual asset may be produced until each shot has:
- entry state;
- active event;
- exit state;
- transition relationship;
- audio cue.

### G3 — Mixed-media minimum
A 35–45s pilot must use at least four meaningful source/treatment families, for example:
- generated conceptual object;
- real evidence/archive;
- photography/cutout;
- line drawing/diagram;
- halftone/print treatment;
- 3D/sculptural object.

No more than two consecutive beats may use the same dominant medium.

### G4 — Visual-event density
Target:
- meaningful visual event every **0.8–1.5s** during active sections;
- intentional breathing holds may reach 2–3s;
- no static 5–8s hold unless the content itself is visually evolving.

### G5 — Cobalt anchor
Cobalt/azure is restored as a recurring structural identity field.
It need not appear in every shot, but must meaningfully recur.

### G6 — Typography is visual content
At least 3 designed typography beats in a 35–45s pilot:
- question/hook;
- explanatory number/fact;
- closing synthesis.

### G7 — Human interaction
At least one transition or visual beat should involve a credible hand/person interacting with the subject when narratively appropriate.

### G8 — Professional finishing only
Descript remains:
- script/transcript/audio rough tool.

It is not:
- primary motion compositor;
- final picture finishing tool.

### G9 — Audio target
Final retry master:
- -14 to -16 LUFS integrated;
- <= -1 dBTP;
- 48 kHz;
- dialogue remains clearly dominant.

### G10 — Review actual render
Council review must inspect:
- full render;
- sampled key frames;
- motion/transition behavior;
- measured audio;
- export metadata.

---

## 8. Final Council statement

The visual identity should **not** be discarded.

What must be discarded is the assumption that the identity is primarily:
> ivory + tactile paper object + soft shadow.

The actual adopted identity is better described as:

> **Kinetic Editorial Surrealism — a high-contrast mixed-media system combining cobalt fields, editorial typography, photography, human interaction, archive, diagrams, print texture, sculptural objects and object-caused transitions.**

The retry should preserve conceptual intelligence and negative space from P1 while rebuilding the temporal grammar from the reference.
