## Operating doctrine

The channel is broad in subject but narrow in editorial promise:

**Reveal the hidden logic behind something familiar, strange, important, or easy to overlook.**

The Council does not imitate studio headcount.
It adopts studio disciplines.

The benchmark reference set includes:
- Kurzgesagt
- Veritasium
- Simplicissimus / fern
- Cleo Abram / Huge If True
- Johnny Harris

## What changed in v1.3

The studio now uses a small always-active core and stage-routed craft capabilities, adds an explicit Cinematography / Shot Design stage before the animatic, and requires recoverable application handoffs with checkpoints and UNKNOWN-state reconciliation.

The v1.2 studio-benchmarked disciplines remain in force.

The media system now treats production as a professional editorial studio rather than an AI-agent sequence.

New required disciplines:
- Media Producer / Production Coordinator
- Independent Fact Checker
- dedicated Thumbnail & Packaging Designer
- Visual Story Case
- Pre-production Craft Review
- five-pass script development
- separate Claim Source and Visual Source/Rights ledgers
- Production Readiness Gate
- editor participation before Script Lock
- early and late packaging stages

## Professional workflow

### 1. Signal Capture
Growth collects cross-platform signals.

### 2. Topic Clustering
Signals become durable questions.

### 3. Topic Scorecard
100-point topic score; minimum 75.

### 4. Evidence Pack
Build two separate ledgers:
- Claim Source Sheet
- Visual Source / Rights Sheet

### 5. Visual Story Case
Before serious scripting, answer:
**Why is this a video rather than an article?**

Required:
- key visual
- key demonstration/diagram
- archive or real-world evidence
- visual transformation/reveal
- editor feasibility note

Fail:
return to backlog or reframe.

### 6. Packaging Hypotheses — Stage A
Before script lock:
- 5 title hypotheses
- 3 thumbnail hypotheses
- click promise
- answer promise

### 7. Story Thesis
One question.
One answer.
One narrative turn.
One ending insight.

### 8. Pre-production Craft Review
Showrunner + Producer + Research + Motion + Art + Sound + Growth meet before Script Lock.

They test:
- story clarity
- visual viability
- first-30-second pacing
- sonic opportunities
- evidence weakness
- production cost
- tool gaps
- packaging/story mismatch

### 9. Script Development
Five purposeful passes:

S0 — Story Skeleton
S1 — Evidence Draft
S2 — Visual Draft
S3 — Voice/Performance Draft
S4 — Locked Script

Single-pass scripting is forbidden.

### 10. Independent Fact Check
Fact Checker clears material claims.

Researcher/writer cannot be sole factual approver.

### 11. Script Lock
Showrunner locks story.
Producer records version and downstream impact.

### 12. Visual Treatment
Art Director defines:
- visual thesis
- palette subset
- unique motifs
- diagram language
- hero objects

### 13. Audio Spotting + Sonic Concept
Sound is designed with picture.

### 14. Reference Frame Assignment
Minimum 8; target 12.

### 15. Shot Design + Camera Plan
Cinematography / Shot Design defines shot purpose, framing, shot size, camera motion, depth, staging, screen direction, continuity and transition motivation.

No camera move exists only to make the shot feel expensive.

### 16. Storyboard + Transition + Audio Map
Every major beat connects:
picture + narration + music + SFX + transition logic.

### 17. Asset Registry
No unregistered asset enters production.

### 18. Animatic
Cheap timing test before expensive production.

### 19. Production Readiness Review
Production does not start until:
- script locked
- independent fact check passed
- key visuals approved
- claim sources complete
- visual rights clear
- storyboard sufficient
- audio spotting complete
- asset registry ready
- required specialized tools available
- schedule acceptable
- budget acceptable

Fail:
**HOLD_PRODUCTION**

### 20. Narration Recording + Dialogue Edit
Owner narration remains channel identity.

### 21. Production
Gather/create/animate assets.

### 22. Editorial Rough Cut
Editor shapes story, pacing and visual rhythm.

### 23. Packaging Finalization — Stage B
After rough cut:
- final title variants
- final thumbnail variants
- mobile-legibility review
- A/B test plan

### 24. Picture Lock
Showrunner approves picture timing.

### 25. Music + Sound Design
Final detailed sound work against locked picture.

### 26. Mix + Master
Dialogue/Mix Engineer creates technical master.

### 27. Audio-Visual Sync QC
Picture and sound reviewed as one system.

### 28. Multilingual Preflight
Language-safe master verified.

### 29. Anti-Slop Gate
Reject:
- interchangeable scripts
- generic AI composition chains
- filler B-roll
- generic repeated sound language
- decorative transitions
- synthetic narration cadence

### 30. Fact / Policy / Continuity QC
Final factual, rights and continuity check.

### 31. Export QC
Delivery integrity.

### 32. Owner Publish Gate
Public publication requires explicit Owner approval.

### 33. Analytics Postmortem
Read:
- CTR
- first 30 seconds
- APV
- watch time
- returning viewers
- top moments
- spikes/dips
- comments
- language share

### 34. Memory + Routine Update
Persist only durable learning.

- Visual Story Case
- Story Skeleton

- first-30-second pacing
- transition feasibility

The editor is not a downstream keyboard operator.

## Human assistance lane

Human assistance can be invoked from any production stage when the automated route is blocked, materially uncertain, physically impossible, or inefficient compared with a bounded human action.

This is not a new permanent reviewer.

The Media Producer coordinates the request. The helper receives only the minimum scope required and returns a specific artifact, answer or completed action against explicit acceptance criteria.

Examples:
- Owner completes a login/credential-bound step.
- A technician fixes a desktop/application condition the studio cannot safely resolve.
- A human editor checks a perceptual issue the automated QC cannot confidently judge.
- A domain expert resolves a material factual ambiguity.
- A craft specialist performs one capability the current toolchain does not yet support.

Once the returned work is verified and checkpointed, the studio resumes from the defined return handoff.

Repeated dependence on the same human task is treated as evidence of a capability gap, not as the intended steady-state workflow.
