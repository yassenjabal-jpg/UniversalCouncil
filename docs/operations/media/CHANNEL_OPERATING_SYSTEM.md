## Operating doctrine

The channel is broad in subject but narrow in editorial promise:

**Reveal the hidden logic behind something familiar, strange, important, or easy to overlook.**

The Council does not imitate studio headcount.
It adopts studio disciplines.

The benchmark reference set includes:
- Kurzgesagt
- Veritasium
- Simplicissimus / fern
- Cleo Abram / Huge If True
- Johnny Harris

## Professional workflow

### 1. Signal Capture
Growth collects cross-platform signals.

### 2. Topic Clustering
Signals become durable questions.

### 3. Topic Scorecard
100-point topic score; minimum 75.

### 4. Evidence Pack
Build two separate ledgers:
- Claim Source Sheet
- Visual Source / Rights Sheet

### 5. Visual Story Case
Before serious scripting, answer:
**Why is this a video rather than an article?**

Required:
- key visual
- key demonstration/diagram
- archive or real-world evidence
- visual transformation/reveal
- editor feasibility note

Fail:
return to backlog or reframe.

### 6. Packaging Hypotheses — Stage A
Before script lock:
- 5 title hypotheses
- 3 thumbnail hypotheses
- click promise
- answer promise

### 7. Story Thesis
One question.
One answer.
One narrative turn.
One ending insight.

### 8. Pre-production Craft Review
Showrunner + Producer + Research + Motion + Art + Sound + Growth meet before Script Lock.

They test:
- story clarity
- visual viability
- first-30-second pacing
- sonic opportunities
- evidence weakness
- production cost
- tool gaps
- packaging/story mismatch

### 9. Script Development
Five purposeful passes:

S0 — Story Skeleton
S1 — Evidence Draft
S2 — Visual Draft
S3 — Voice/Performance Draft
S4 — Locked Script

Single-pass scripting is forbidden.

### 10. Independent Fact Check
Fact Checker clears material claims.

Researcher/writer cannot be sole factual approver.

### 11. Script Lock
Showrunner locks story.
Producer records version and downstream impact.

### 12. Visual Treatment
Art Director defines:
- visual thesis
- palette subset
- unique motifs
- diagram language
- hero objects

### 12A. Visual Generation Brief Compile + Anti-Slop Approval

Before any generated visual is executed, the Council produces a versioned **Visual Generation Brief**.

Compiler:
- Visual Art Director / Frame Curator
- Thumbnail & Packaging Designer
- Synthesis & Alternatives Designer

Independent approval:
- Red Team / Anti-Slop

Executor:
- Technical Operator

Required template:
`docs/templates/media/VISUAL_GENERATION_BRIEF.md`

Hard rules:
- **NO PROMPT, NO GENERATION**
- **NO ANTI-SLOP APPROVAL, NO EXECUTION**
- Technical Operator may not creatively rewrite the approved brief
- generation tools may not materially reinterpret the approved brief
- material deviation returns to Council
- prompt version + tool/model + execution receipt are recorded

Packaging hypotheses may be conceptual/textual before this gate, but no generated thumbnail asset may be produced before approval.

### 13. Audio Spotting + Sonic Concept
Sound is designed with picture.

### 14. Reference Frame Assignment
Minimum 8; target 12.

### 15. Storyboard + Transition + Audio Map
Every major beat connects:
picture + narration + music + SFX + transition logic.

### 16. Asset Registry
No unregistered asset enters production.

### 17. Animatic
Cheap timing test before expensive production.

### 18. Production Readiness Review
Production does not start until:
- script locked
- independent fact check passed
- key visuals approved
- claim sources complete
- visual rights clear
- storyboard sufficient
- audio spotting complete
- asset registry ready
- required specialized tools available
- schedule acceptable
- budget acceptable

Fail:
**HOLD_PRODUCTION**

### 19. Narration Recording + Dialogue Edit
Owner narration remains channel identity.

### 20. Production
Gather/create/animate assets.

### 21. Editorial Rough Cut
Editor shapes story, pacing and visual rhythm.

### 22. Packaging Finalization — Stage B
After rough cut:
- final title variants
- final thumbnail variants
- mobile-legibility review
- A/B test plan

### 23. Picture Lock
Showrunner approves picture timing.

### 24. Music + Sound Design
Final detailed sound work against locked picture.

### 25. Mix + Master
Dialogue/Mix Engineer creates technical master.

### 26. Audio-Visual Sync QC
Picture and sound reviewed as one system.

### 27. Multilingual Preflight
Language-safe master verified.

### 28. Anti-Slop Gate
Reject:
- interchangeable scripts
- generic AI composition chains
- filler B-roll
- generic repeated sound language
- decorative transitions
- synthetic narration cadence

### 29. Fact / Policy / Continuity QC
Final factual, rights and continuity check.

### 30. Export QC
Delivery integrity.

### 31. Owner Publish Gate
Public publication requires explicit Owner approval.

### 32. Analytics Postmortem
Read:
- CTR
- first 30 seconds
- APV
- watch time
- returning viewers
- top moments
- spikes/dips
- comments
- language share

### 33. Memory + Routine Update
Persist only durable learning.

- milestone slips
- script revision rounds
- fact-check defects caught before lock

## Visual Generation Brief authority

The Visual Prompt / Generation Brief Compiler is a **composed capability**, not a new permanent seat.

Art Director owns visual intent.  
Thumbnail Designer owns packaging readability and differentiation.  
Synthesis converts approved positions into one executable artifact without erasing dissent or constraints.  
Red Team / Anti-Slop approves or rejects the artifact.  
Technical Operator executes the approved artifact and records the receipt.

The executor is not an additional creative decision-maker.

## Visual Production Lock and Pilot Ladder — 2026-10-14

The channel must not scale directly from a thumbnail experiment to an 8+ minute episode.

Governing production sequence:

`P0 Reference Frame Lock → P1 30–45s Coherence Pilot → P2 60–90s Production Pilot → P3 8+ min Episode`

P0 requires:
- 4–6 coherent reference frames from one topic;
- locked Visual Production Kit;
- primary visual-generation route qualified with the same-frame/same-brief protocol.

After P0 lock:
- Visual Art Director owns final visual decisions inside the locked system;
- Technical Operator executes without creative rewrite;
- Red Team can block drift/AI slop/evidence confusion;
- full Council reviews at gates, not every ordinary frame.

Full-length production is **BLOCKED** until P2 passes.
