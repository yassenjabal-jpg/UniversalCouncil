# The Studio — Operating Model v1.0

**Arabic operating name:** الاستوديو  
**English operating name:** The Studio  
**Effective:** 2026-10-15  
**Scope:** active media-production system only.

> Historical repository evidence may still contain the legacy name **Council**. That history is not rewritten. Active media production uses **The Studio / الاستوديو** from this point forward.

## Why this structure exists

The Studio is not a committee and it is not a loose collection of agents. It is a compact documentary production studio.

The structure combines publicly documented production principles from several successful global YouTube organizations:

- **Kurzgesagt:** deep research, source/expert checking, script as backbone, dedicated illustration, voiceover timing before animation, and custom music/SFX.
- **Johnny Harris:** writing and visual direction happen together; narration and screen action are planned as one object; post moves through progressively more refined cuts.
- **Linus Media Group:** project tracking, consistent names/locations, explicit handoffs between writers/visual production/editors, then layered QC.
- **Beast Industries / MrBeast:** separate creative, production and post functions; retention, pacing, stakes, thumbnails and titles are treated as creative decisions.
- **Vox Explainer Studio:** research, reporting, insight, personality and humanity form one explainer identity rather than a repeated visual template.
- **Corridor Digital / Corridor Crew:** invest in pipeline automation for repetitive production work so artists spend more time on creative decisions.

The Studio borrows these principles, not their headcount, budgets or proprietary processes.

## Core doctrine

1. **Story and evidence before polish.**
2. **Write for picture, not prose alone.**
3. **Specialists produce; stage authority decides.**
4. **Packaging and retention begin before the edit.**
5. **Sound begins in preproduction, not after picture lock.**
6. **One central editorial timeline owns the episode.**
7. **Automate repetition, not taste.**
8. **Independent QC reviews the exact final master.**

# Permanent departments

## 1. Studio Management

**Lead:** Media Producer / Production Coordinator

Owns:
- schedule;
- dependencies;
- resources;
- episode traffic;
- stage handoffs;
- review calendar;
- risk visibility;
- delivery readiness.

The Producer does not decide factual truth, visual taste or editorial thesis.

## 2. Editorial & Research

**Lead:** Editorial Director / Showrunner

Members:
- Editorial Director / Showrunner
- Independent Fact Checker
- Script & Voice Director
- Audience Growth & Packaging Strategist

Owns:
- idea;
- audience promise;
- research question;
- evidence spine;
- story thesis;
- two-column AV script;
- narration intent;
- hook and retention logic.

## 3. Visual Design

**Lead:** Visual Art Director / Frame Curator

Members:
- Visual Art Director / Frame Curator
- Thumbnail & Packaging Designer

Shared early member:
- Motion & Picture Editor

Owns:
- visual thesis;
- reference board;
- mixed-media system;
- typography;
- diagrams;
- visual metaphor;
- packaging hierarchy;
- visual continuity.

## 4. Post Production

**Lead:** Motion & Picture Editor

Members:
- Motion & Picture Editor
- Music Supervisor & Sound Designer
- Dialogue & Mix Engineer

Conditional:
- Localization Producer

Owns:
- picture edit;
- motion graphics;
- compositing;
- narration continuity;
- sound spotting;
- SFX/music integration;
- rough/final mix;
- subtitles and localization conform.

## 5. QC & Delivery

**Lead:** Independent QC Reviewer

Cross-check:
- Independent Fact Checker

Owns:
- exact-master review;
- full playback defect log;
- codec/resolution/audio measurements;
- rights/fact spot-check;
- export hash;
- delivery evidence.

# Episode Pod

Departments remain permanent, but each video is executed by a temporary **Episode Pod**.

The Pod always includes:

- Producer
- Showrunner
- Fact Checker
- Script & Voice Director
- Art Director
- Motion & Picture Editor
- Sound Designer
- Mix Engineer
- Growth Strategist
- Thumbnail Designer
- Independent QC Reviewer

Localization joins only when a localized version is requested.

This prevents two failure modes:
- twelve isolated specialists working independently;
- one generalist doing everything while specialists only comment at the end.

# Five-stage Studio workflow

Technical stage IDs remain unchanged for compatibility. Studio-facing names change.

## Stage 1 — Development Room
Technical ID: `research_script`

**Lead:** Showrunner

Goal:
Lock the audience promise, evidence spine, thesis and audiovisual script before expensive production begins.

Required outputs:
- Topic Brief
- Claim Ledger
- Two-Column AV Script
- Narration Performance Map
- Hook / Retention Notes

### Two-Column AV Script

Every meaningful narration beat should carry:
- what is said;
- what the viewer sees;
- source/evidence ID when factual;
- motion/transition intent where needed;
- audio opportunity where meaningful.

This adopts the useful principle from Johnny Harris: writing and visual direction are not independent documents that meet for the first time in editing.

## Stage 2 — Preproduction Blueprint
Technical ID: `visual_direction`

**Lead:** Art Director

Goal:
Turn the story into one visual/sonic/packaging system.

Required outputs:
- Visual Treatment
- Reference Board
- Motion Feasibility Map
- Sonic / Visual Intent
- Packaging-Hook Continuity Note

Sound and thumbnail strategy start here, not after the picture is finished.

## Stage 3 — Production Pack
Technical ID: `asset_pack`

**Lead:** Producer

Goal:
Deliver everything Post needs in one rights-aware production package.

Required outputs:
- Asset Manifest
- Visual Asset Clearance
- Music / SFX Asset Plan
- Dialogue / Mix Input Specification
- Thumbnail / Packaging Specification

Work happens in parallel:
- archive/evidence assets;
- photographic/generated assets;
- graphics/vector assets;
- music/SFX;
- packaging source material.

### Gate A — Greenlight / Preproduction Lock

This is the existing `Preproduction Lock`.

Post production does not begin unless story, evidence, visual direction, sound intent, packaging intent and asset readiness are all present.

No extra gate is created.

## Stage 4 — Post Production
Technical ID: `edit_motion`

**Lead:** Motion & Picture Editor

Goal:
Build one authored continuous film, not a collection of independently polished shots.

Order:
1. radio/story cut;
2. picture assembly;
3. motion/compositing;
4. sound design + rough mix;
5. one consolidated Rough Cut Review;
6. targeted conform.

Required specialist outputs:
- Narration Continuity Notes
- Spotting Sheet
- Rough Mix Receipt
- Visual Conform Notes

### Gate B — Rough Cut Room

This is the existing `Rough Cut Review`.

The Showrunner watches the continuous cut.
Art, Sound, Growth and factual specialists submit their notes into one timecoded note set.
The Showrunner resolves conflicts.
One normal revision round remains the target.

This is not a committee vote.

## Stage 5 — Master QC & Delivery
Technical ID: `final_qc`

**Lead:** Independent QC Reviewer

Required outputs:
- Final Mix Receipt
- Final Fact Spot-Check
- Technical Measurements
- Full Playback Defect Log
- Exact Master Hash

### Gate C — Master QC

This is the existing `Final QC`.

The QC reviewer must be independent of edit and mix authors.
Owner publication authority remains separate and explicit.

# Four continuous loops

These run across stages instead of appearing late.

## Evidence loop
Research → claim ledger → visual evidence → final fact spot-check.

## Packaging loop
Hook hypothesis → packaging continuity → thumbnail spec → rough-cut alignment → post-publish CTR learning.

## Sound loop
Sonic intent → music/SFX plan → spotting sheet → rough mix → final mix.

## Visual motif loop
Story thesis → visual metaphor → asset treatment → motion transformation → visual conform.

# Handoff contract

Every episode uses one Episode ID across:
- documents;
- project folders;
- NLE project;
- AE comps;
- audio session;
- review versions;
- export;
- QC receipts.

Every handoff declares:
- owner;
- artifact;
- version;
- SHA/hash where applicable;
- unresolved defects;
- next receiver.

Approvals cannot exist only in chat.

When media exists, review notes should be timecoded.

# Packaging / retention doctrine

Borrowing the useful part of the MrBeast creative model does **not** mean imitating challenge videos.

It means:
- every opening decision has a viewer-retention purpose;
- each cut must solve a story or attention problem;
- the editor should be able to explain why a cut exists;
- title/thumbnail promise must match the actual story;
- growth analysis informs craft but never overrides factual integrity.

---

# Automation doctrine

Corridor's useful lesson is not “use AI everywhere.” It is:

> remove repetitive technical friction so creative people spend time on creative decisions.

Automate:
- naming;
- folder/project creation;
- ingest manifests;
- versioning;
- render queues;
- transcodes;
- checksums;
- technical QC;
- evidence receipts.

Do not automate away:
- thesis;
- factual judgment;
- visual metaphor;
- edit rhythm;
- musical emotion;
- thumbnail hierarchy;
- final taste.

# Tool ownership after qualification

The intended tool map remains provisional until each program passes the Studio qualification protocol.

- Premiere Pro → central picture/editorial timeline
- After Effects → motion/VFX/compositing
- Audition → narration/sound/mix
- Photoshop → thumbnail/raster compositing
- Illustrator → diagrams/vector systems
- Media Encoder → queue/delivery
- Zotero → source library
- PureRef → reference boards
- Subtitle Edit → localization/subtitles
- MediaInfo + Youlean → independent technical/audio QC
- vidIQ + YouTube Studio → audience/packaging evidence

Installation alone does not qualify a tool.
