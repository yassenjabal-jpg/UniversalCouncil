# Packaging Bible v1

## Principle

The thumbnail and title must work together, not duplicate each other.

Title = precise story/question promise.
Thumbnail = visual tension / contradiction / object.

Do not put the entire title on the thumbnail.

## Thumbnail visual language

Use the same channel world:
- cobalt / sky blue / ivory / brass;
- editorial negative space;
- one dominant hero object or face;
- optional classical/scientific element;
- strong silhouette;
- minimal words.

Preferred text:
0–4 words.

Avoid:
- red arrows/circles by default;
- shocked AI faces;
- five unrelated objects;
- tiny explanatory copy;
- repeated identical template;
- fake numbers;
- visual claims the episode does not prove.

## Thumbnail families

T01 Object + Question
T02 Person + Mechanism
T03 Before/After Contrast
T04 Diagram Mystery
T05 Scale / Impossible Number
T06 Map / Hidden Route

The family may repeat; the composition cannot be mechanically copied.

## Title rules

Good:
- one concrete question;
- one contradiction;
- one hidden mechanism;
- one object viewers recognize.

Weak:
- generic "Everything you need to know";
- vague "The truth about";
- artificial urgency;
- excessive punctuation;
- title that requires thumbnail text to make sense.

## Packaging gate

Before script lock:
- 5 title candidates;
- 3 thumbnail sketches;
- one click promise;
- one answer promise;
- one likely viewer misconception.

## A/B learning

When YouTube Test & Compare is available:
- test materially different concepts, not font/color variants;
- store results;
- do not overfit one test;
- feed durable packaging lessons into the postmortem.

## Multilingual packaging

Do not assume direct title translation is best.
Each language version gets:
- semantic translation;
- click-intent check;
- cultural clarity;
- line-length check;
- thumbnail text localization when needed.
