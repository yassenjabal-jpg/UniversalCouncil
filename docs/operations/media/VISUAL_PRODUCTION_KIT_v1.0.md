## 2. Color
- Paper Ivory: approx. `#F2EFE8`
- Ink Charcoal: approx. `#1D1B1A`
- Electric Cobalt/Azure: optional brand anchor, never mandatory
- Episode accent: one subject-driven accent; DAY24 uses deep plum/mineral red
- Accent budget: normally <10% of frame area
- Saturation: controlled; no neon default
- Forbidden default combination: blue + gold + marble as shorthand for “premium”

## 3. Typography
- Arabic display: **Noto Kufi Arabic Bold/SemiBold** direction; compact 2–4 word headlines for thumbnails
- Arabic body/labels: **Noto Sans Arabic Regular/Medium** direction
- Latin/numbers: **Source Serif 4** direction for editorial contrast
- One primary text block per key frame
- Typography added deterministically in design/editing tools; image models do not render final Arabic text
- Large negative space around headline is mandatory

## 4. Grid + negative space
- Base grid: 12-column editorial grid
- Key-frame negative space: normally 35–60%
- Thumbnail target: normally 40–55%
- Dominant focal points: 1
- Secondary focal point: max 1 when narratively necessary
- Asymmetrical balance preferred
- Crop may break frame edge deliberately
- Never fill empty space merely to make an image “richer”

## 5. Image-source treatments

### Archive / evidence
- content remains source-faithful;
- no generative rewriting of evidence;
- place inside clean editorial holder, crop or frame;
- optional charcoal border / ivory mount / tiny accent registration mark;
- label provenance outside the image when needed.

### Modern photography
- clean cutout or disciplined crop;
- avoid cinematic relighting that falsifies documentary context;
- subtle paper/print integration allowed.

### Generated conceptual image
- explanation/atmosphere only;
- one metaphor;
- one hero;
- clearly not passed off as archival fact.

### Diagram
- flat or tactile paper geometry;
- charcoal rules;
- one accent marker;
- no dashboard/HUD aesthetic.

### Painting / engraving
- use only when historically relevant;
- editorial crop/cutout rather than museum-frame default.

### Documents / maps
- source-faithful;
- highlight with restrained lines/masks, not fictional annotations.

## 6. Surface + texture
- subtle premium paper grain is canonical
- light halftone/print touch allowed
- tactile card/paper thickness allowed for conceptual objects
- material realism should support the idea, not become luxury spectacle
- no fake parchment, cracks, ornate stone or gold distress as default

## 7. Lighting + shadow
- default: soft upper-left studio light for conceptual objects
- shadow: one restrained soft contact/floating shadow
- no volumetric haze
- no dramatic sunset lighting unless topic-specific
- no glossy product-ad look by default

## 8. Frame families

### Hero Question
Purpose: pose the episode's central visual question.
Rules: one memorable metaphor, mobile-readable silhouette, strongest negative space.

### Object Macro
Purpose: make a process/material detail become the story.
Rules: extreme crop; no need to show whole object; detail density remains local.

### Evidence / Archive
Purpose: prove factual claims.
Rules: real source content only; system styling happens around it, not by rewriting it.

### Diagram / Mechanism
Purpose: explain relationships and systems.
Rules: simple geometry, visible causality, charcoal + one accent, labels added deterministically.

### Editorial Cutout
Purpose: introduce human presence or historical/modern contrast.
Rules: real photo/archival cutout preferred; generated mannequin look is not a recurring motif.

### Conceptual Surrealism
Purpose: compress an abstract idea into one impossible-but-clear relationship.
Rules: one surreal move only; no spectacle stack.

### Breathing Reset
Purpose: pacing and visual rest.
Rules: high negative space; one material/object gesture; low information density.

## 9. Diagram language
- line weight: visually consistent medium-fine charcoal
- accent: one plum/episode-color marker
- arrows: simple straight/curved arrows only when causality needs them
- labels: deterministic typography, never AI-generated
- numbers: Source Serif 4 / editorial serif direction
- animation: lines build from cause to effect
- no glowing HUD, gradients-for-decoration, or generic infographic icon packs

## 10. Motion grammar
Preferred:
- object-caused reveal
- groove/line build
- paper/ribbon fold
- archive insertion
- shape match
- cutout entrance
- page/field shift
- mask reveal
- photo-to-diagram extraction
- restrained parallax
- color-field reset

Avoid:
- random whip pans
- glitch
- preset transition packs
- motion applied equally to every element
- camera movement with no semantic purpose

## 11. Continuity
Stable across a sequence:
- editorial spacing
- paper/print tactility
- disciplined palette
- one-idea frames
- restrained shadows
- deterministic typography
- meaning-driven transitions

May change shot-to-shot:
- layout family
- hero type
- camera/crop
- dominant field color
- amount of texture
- image source type

Must change episode-to-episode:
- visual metaphor
- hero object
- episode accent
- episode-specific motifs
- unique transition motif

## 12. Evidence boundary
Evidence = real/source-faithful.
Explanation = diagrams/conceptual frames.
Atmosphere = clearly illustrative.
Synthetic historical realism may never impersonate archive.

## 13. Anti-Slop lock
Reject:
- more objects than the idea needs;
- cinematic fantasy for its own sake;
- blue/gold/marble default;
- repeated circle/radial template across unrelated episodes;
- repeated hand/historical sleeve;
- generic gears for “systems”;
- fake archive;
- AI text;
- architecture without topic reason;
- detail filling negative space;
- identical layout copied from previous episode.

## 14. Operator authority
Technical Operator may:
- execute approved prompt/brief;
- choose only qualified route according to policy;
- adjust export/runtime settings that do not alter art direction.

Technical Operator must return to Art Director for:
- material composition deviation;
- unexpected extra objects;
- palette drift;
- source-treatment ambiguity.

Return to full Council only for:
- brand-system exception;
- evidence risk;
- unresolved Red Team block;
- genuinely new visual language.
